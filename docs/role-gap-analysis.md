# InfraScan: Role Completeness Gap Analysis

This document provides a comprehensive audit of every feature across the four primary operational roles (**Infrastructure Inspector**, **Civil Engineer**, **Maintenance Engineer**, **Infrastructure Manager**) as defined in the InfraScan Specification and Prompt Sections 5 through 8.

Status categories:
- **Exists and works**: Fully implemented in backend, database, and UI; verified operational with real data.
- **Exists but broken**: Implemented but contains bugs, broken links, or specification violations (e.g. mock data, incorrect status lifecycle, missing permission checks).
- **Partial**: Partially built (e.g. API exists but UI is missing/mocked, or UI exists without real backend wiring).
- **Missing**: Not yet implemented.

## Traceability & Implementation Plan

The features above will be built in the required sequential order:
1. **Cross-Cutting Data Model (Section 10)**:
   - Alembic migration and SQLAlchemy models: `Detection`, `Measurement`, `Review`, `PriorityRecommendation`, `SeverityRule`, `PriorityRule`, `RepairTaskTemplate`, `WorkOrder`, `WorkOrderEvent`, `InspectionComparison`, `Report`, and `Asset.region`.
   - Core engines: Preprocessing pipeline, server-side geometry & measurement engine, severity rule engine, maintenance priority engine, OpenCV registration engine, multi-format report generator.
2. **Infrastructure Inspector (Section 5)**:
   - INS-1 to INS-15: Upload lifecycle, 7 validation checks, calibration dialog, submit locking, preprocessing stepper with Original/Processed toggle, review outcome card.
3. **Civil Engineer (Section 6)**:
   - ENG-1 to ENG-22: Review queue with claiming, interactive review workspace (polyline, width lines, polygon, ROI), server-side recomputation, geometry verification, severity & priority rule engines, signoff locking, multi-format reports, progression comparison.
4. **Maintenance Engineer (Section 7)**:
   - MNT-1 to MNT-10: Work orders table, detail with linked reviewed image & annotation, status transition engine with event history, follow-up inspection requests, repair templates.
5. **Infrastructure Manager (Section 8)**:
   - MGR-1 to MGR-12: Reviewed-only dashboard metrics, Leaflet damage map with text labels & inspection routes, hotspot summaries, priority list.
6. **Visibility & Integration Tests (Section 12)**:
   - Automated pytest & Playwright end-to-end tests verifying role data isolation, 403/404 gates, and full image journey from capture to closed work order.
